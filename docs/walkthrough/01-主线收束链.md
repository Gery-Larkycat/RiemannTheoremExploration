# 解读 01 — 主线收束链：12 行门面与 32 行经典桥

> 解读系列按我们的侦察顺序成文。本文对应第一轮侦察：从 Main.lean 走到证明引擎的门口。

## 1. 门面：Main.lean（全文 12 行）

整个 17,374,215 行证明的最终交付物是 5 个定理：

- riemannHypothesis : RiemannHypothesis —— RH 本体
- riemannZeta_eq_zero_re —— ζ 非平凡零点全在临界线（等价重述）
- LFunction_ne_zero_of_half_lt_re —— GRH 右半带：L(s,χ) 在 Re(s)>1/2 无零点
- LFunction_eq_zero_re / _of_isPrimitive —— GRH 临界带：带内零点全在临界线上（一般/本原特征）

Lean 读法：每个定理 = 声明（冒号前的名字，冒号后的类型）+ 证明（:= 后面的项）。五个定理的证明全是"引用"，真正的词只有 rhOfAll / allChi / claimAll / critAll。

## 2. 声明层：Statements.lean（16 行）

四条 Prop 的数学含义（详见数学背景笔记 01）：

- RiemannZetaZerosOnLine：ζ 的每个零点（排除负偶数平凡零点与 s=1 极点）实部 = 1/2
- DirichletLNonvanishingRightOfHalf：右半带无零点（注意 χ≠1 ∨ s≠1 排除主特征的平凡极点）
- DirichletLZerosOnLine / PrimitiveDirichletLZerosOnLine：临界带零点在镜面上

## 3. 收束层：Supplements/Kernels（22 行）

MainTheorems.lean：allChi（引擎输出）→ rhOfAll（桥）→ critAll/claimAll（GRH 两个方向）。
值得注意：目录名 Kernels（核）——整个证明的"可执行内核"仅 22 行，其余 1737 万行都是为这 22 行供弹药。

## 4. 桥：Formalism/GammaFactorNonvanishing/CritLine.lean（32 行，全文已读）

三步，全经典：

1. gammaFactor_ne_zero：偶/奇特征的 Γ 因子分别在 Re(s)>0 非零（GammaR_ne_zero_of_re_pos）
2. critLine：反证 + 函数方程反射。左半带零点 → χ⁻¹ 的完成 L 在 1−s 为零 → 拆成 L 零点（Γ 因子非零）→ 落入右半带 → 与 EveryCharacter 矛盾
3. rh_of_every：模 1 主特征退化为 ζ，经 RhOfRight 收口

数学背景：这是 Hadamard–de la Vallée Poussin 1896 结构的完整版——见数学背景笔记 01。

## 5. 本轮结论

主线一层没有任何新数学——它是一座精心搭建的"经典结构骨架"。证明的新颖性全部在引擎输出 UpperTheory.EveryCharacter 的内部：为什么右半带对所有特征无零点。
