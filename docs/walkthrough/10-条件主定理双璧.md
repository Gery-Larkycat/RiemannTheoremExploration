# 解读 10 — 条件主定理双璧与命名空间组织学

> 对应第十轮侦察。形式桥网络的理论核心出土：两条"Gz 幂界 ⇒ 零点自由/RH"的条件定理；同时澄清 AI 代码的组织学现象。

## 1. 条件主定理双璧（SizeWindowBrackets/PowerBoundGivesRiemannHypothesis.lean）

namespace Formalism.LFunctionChainParameters.ConditionalMainTheorem：

1. **LandauZeroFreeHalfPlane**：若对每个 y ≥ y0 都有 Gz y ≤ y^θ，则 zeta(s) 在 Re(s) > θ 无零点。
   —— **只用主特征主项 Gz 就能约束 zeta 本身**。这是经典 Landau 定理的直译：Gz y = 对 n≤y 求和 vonMangoldt(n)·(y/n−1) 的截断 与 zeta 的零点自由区互为对偶（素数定理级别：psi(x)~x 当且仅当 Re=1 无零点；指数 1/2+eps 截断 当且仅当 Re≤1/2+eps 无零点）。

2. **PowerBoundGivesRiemannHypothesis**：若对每个 eps>0 最终恒有 Gz x ≤ x^(1/2 + C·eps)，则 **RiemannHypothesis 成立**。
   —— 把截断指数压到 1/2（任意 C 与 eps→0）=> RH。这就是"幂界给出 RH"的精确含义：**RH 当且仅当 Gz 的增长指数 = 1/2**。

**组织学结论**：Formalism 库的 SizeWindowBrackets（尺寸窗括号，64 文件 / 28,345 行）物理承载了 LFunctionChainParameters 逻辑家族——LChain/LHost/LErr/characterSumData/ThickSetMeanBounds/WeightedSlopeBounds/ConditionalMainTheorem 等子命名空间全部定义于此目录的文件内（namespace 与物理路径完全解耦）。其中 ChainSlopeWindows/ 子目录（素数同余条件、log2 下界、阈值幂次）是常数预算（如 eD+eL+7）的推导地。

## 3. 双通道结构：zeta 通道与 GRH 通道

综合十轮侦察，证明存在两条并行通道：

- **zeta 通道（主特征）**：Gz 截断 →（LandauZeroFreeHalfPlane / PowerBound）→ RH。理论上 Gz 只依赖素数计数——经典路线的天然领地。
- **GRH 通道（全体特征）**：EveryCharacter（宿主舞台 + Poitou-Tate + 标签字典压制每个非主特征的波）→ critLine/VW 桥 → 含 RH。

实际证明走哪条？MainTheorems.lean 的 rhOfAll 经 rh_of_every（EveryCharacter 路线）——即**实际路径是 GRH 通道**，zeta 通道的条件定理是形式桥库中的理论接口（或历史/组织产物）。PowerBoundGivesRiemannHypothesis 与 HalfLinks/ChainCore 等一起构成"可替换攻击面的接口层"——这正是形式桥网络的工程学意义：**证明的最终装配可以在多条等价通道中选择**。
