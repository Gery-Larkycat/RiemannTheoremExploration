# 解读 38 — 相位函数理论栈：迷向消失、对偶分解与 √p 界

> 对应第三十八轮侦察。GL3Theta 200-260 行——相位函数（PhOn/phAt/be/hP）的完整理论栈，HeightAndVanishing 的数学引擎室。

## 1. PhIsotropic：迷向消失【消失机制完全体】

PhIsotropic：对**迷向组** b（所有 hP(b_e, b_e') = 0）且 Primitive（本原）时：

**PhOn b ≃ 0** —— 相位级数完全消失！

**这就是 HeightAndVanishing（高度与消失）的数学引擎**：高度条件给出向量组的迷向性（hP 双零），迷向性给出相位消失，消失给出界——解读 18 三区定性的「消失」一词在此获得精确含义。

## 2. PhUnitary：正交分离

正交系（hP 正交 δ_ij）下：**PhOn b ≃ Σ_k phAt(Xv k)** —— 正交基上相位**可加分离**（不耦合）。

## 3. PhDual + DualIso + beSum：对偶分解

DualIso b b'：b 与 b' **互双正交**（hP(b_e, b'_e') = δ_ij）。此时：**PhOn(b ∪ b') ≃ Σ_e be(Xv(inl e), Xv(inr e))（beSum）**——对偶对上相位分解为纯 be 项。

## 4. jetsPh：相位的射流积分性与 √p 界【平方根截断再现】

jetPh i := i! · coeff_i(ex 经 ph 代换) —— 相位的射流系数（导数）。

- i ≠ 2 ⇒ jetPh i 是 p-adic 整数
- α ∈ O_Kp ⇒ (α.1 − α.2)·jetPh 2 是 p-adic 整数（**差嵌入补偿**）
- p ≠ d ⇒ jetPh 2 是 p-adic 整数
- **p = d ⇒ ‖jetPh 2‖ ≤ p^(1/2)** —— 平方根截断在相位射流层再现！

**解读**：临界素数 p = d（宿主素数）处，相位射流 2 分量被平方根界压住——与解读 16 Kato 定理的临界排除（2r ≠ k）同构的**临界例外结构**。

## 5. atTwo：2-挠点的真奇性

对 2-挠点 t0（IsTwoTorsionPointUnkilled）：th0（U1 归一化）的 log ≃ 0（消失），但 **2-挠平移的 U1 级数积分且系数增长不被任何 ρ < 1 界住**——**2-挠点处有真奇性**（增长率超几何）。

**解读**：素数 2 的特殊性在此定谳——2-挠点携带真奇性（不能被平滑），必须被「宿主素数对」结构单独处理（解读 26 的 2-adic 结构）。
