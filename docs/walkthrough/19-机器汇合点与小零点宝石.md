# 解读 19 — 机器汇合点、WinPair 上界推导与小零点宝石

> 对应第十九轮侦察。三个碎片各自有价值：两台机器的汇合等式、WinPair 上界推导、小零点一致带。

## 1. 机器汇合点：gChi = Gchi（pairEx.lean:61）

pairEx_g：**对非主特征 χ，Formalism.HC.An.gChi χ y = Gchi χ y**——Landau 复量（解读 07）与均方正项和（解读 18）在此**恒等**。

Gchi 的展开同时定格：**Gchi χ y = Σ_{n ≤ ⌊y⌋} Λ(n)·χ(n)·max(y/n − 1, 0)**——von Mangoldt 权 × 特征 × **ramp 权 max(y/n−1, 0)**（log(y/n) 的线性下近似的完整版——此前 CritLine/An.G 的 y/n−1 是 max 的非平凡支）。这就是 Landau 积分离散化的**精确**定义（Σ Λ(n)χ(n)·log(y/n) 的 ramp 近似），之前从多个侧面瞥见的量在此定格。

**架构意义**：Landau 机器（TotientGaloisClasses/Landau.lean）与均方机器（MeanSquareBounds）共享同一个正项和对象 Gchi——两台机器在对象层面汇合，说明"引擎的解析侧"是一个统一的 Landau+均方体系，不是两套平行系统。

## 2. WinPair 上界的推导（log_exp_product_bounds）

设 exp(1 + log 8M) ≤ Y，w = Y^(eps/5)：

Y^(eps/6) ≤ log(8M·e^w·(e^(w·log²Y))^j) ≤ 3·w·log²Y

⇒ **WinPair 的 log q ≤ Y^(eps/5) 与 log d ≤ Y^(eps/5)·(log Y)² 上界的出处**（3 系数即此引理的粗化系数；8M 中 8 与 mod 8 呼应）。log_exp_product_bounds 是"指数/对数预算"的簿记引理——ε/6 与 ε/5 的配比在此可见。

## 3. 小零点宝石（SmallZeros.lean，47 行全文）

NoExc c chi：**beta 距 1 不超过 c 且 beta ≠ 1 时 L(beta, chi) ≠ 0**——"1 的 c-邻域内无零点"。

三级论证：

1. noExc_one：**L(1, chi) ≠ 0（非主特征，Mathlib 已有）+ 连续性 ⇒ 存在邻域**——连续性兜底模式
2. noExc_level：固定模 N 只有有限多个特征 ⇒ 取最小 c
3. small_zeros：**对每个 N₀，存在一致 c₀，所有 N ≤ N₀ 的非主特征在 (1−c₀, 1) 内一致无零点**（对 N₀ 归纳，逐层取 min）

**解读**：主引擎（Chebyshev 窗口 + 平方根截断）管 Re > 1/2 的大范围；SmallZeros 提供 **Re 接近 1 处的兜底带**（L(1,χ) ≠ 0 是解析数论的入口级事实——Dirichlet 1837 证明素数无穷多在等差级数中的关键一步）。大小两层配合，覆盖完整。

另注：namespace QH（MeanSquareBounds 的容器）——QH.pairEx / QH.small_zeros / QH 侧的量词体系；QH 语义待定（Quantitative Hypotheses?）。
