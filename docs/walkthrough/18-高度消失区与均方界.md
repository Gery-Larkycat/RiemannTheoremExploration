## 2. MeanSquareBounds：均方分析区（36 文件）

核心词汇：**GaussSumFunctionEq（Gauss 和）**、MeanSqAbs / meanSqK（均方量）、**pairEx / PairExists / PairShare（素数对存在性——supplyOfAdmOf 所用的 QH.pairEx 在此）**、pairEx_lift（N|L 提升）/ pairEx_box（Rows + 8M < q 盒）/ pairEx_g（非主特征 g 量）、CountBad / BadShare（坏份计数）、PsiThin / Thin / IntThin（薄化）、Kappa4Loglog / kappaC（κ·loglog 常数）、Stage1Succ / StagePow（阶段推进）、TwistPrim / twistK（扭转）、**SmallZeros（小零点！）**、GIntegral。

定性：**特征和的均方（L²）估计区**——Gauss 和是傅里叶对偶的核心对象，均方估计（mean square）是"平均而言特征和多大"的标准问法。pairEx 把素数对存在性作为均方界的推论（均方小 ⇒ 坏对少 ⇒ 好对存在——大筛式排除法）。
