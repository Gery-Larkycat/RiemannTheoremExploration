# 解读 09 — Gz 主项、族连通与 Sha 级数：引擎语义完全体

> 对应第九轮侦察。三个定义（Gz / FamilyClassConnected / HypV）与一个展开定理（vvRecord）使引擎语义完全透明。

## 1. Gz：主特征的正项主项（PrimitiveCosets/GzEq.lean）

theorem Gz_eq : Formalism.Gz y = An.G y ∧ An.G y = Deduction.G y

三个表示统一为（从证明体可见 An.G 的展开）：

**An.G y = Σ_{n ≤ ⌊y⌋} vonMangoldt(n) · (y/n − 1)**

这正是**主特征（χ=1）的正项显式公式主项**：

- 经典：ψ(y) ≈ y（素数定理主项）；Landau 离散版：Σ Λ(n)·log(y/n)
- y/n − 1 是 log(y/n) 的线性下近似（n ≤ y 时 0 ≤ y/n − 1 ≤ log(y/n)）
- Deduction 侧用 ramp（斜坡函数）重写同一和式（Deduction.ramp 实部）

⇒ **Gm = Gz（主项）+ Σ wt·Re(gChi)（非主特征的波）**——与解析理论中 ζ（主特征）与 L(s,χ)（非主）的分离完全同构。引擎的显式公式架构 = 主项 + 波，其中主项有闭式（可精确估计），波被宿主舞台压制。

## 2. FamilyClassConnected：族连通的真身（DivinNOfHypV.lean:13）

def FamilyClassConnected (ℰ : FamClass) : Prop :=
  ∃ eD eL ε₁ > 0, ∀ eps < ε₁, ∃ Fm : FamP eps, ℰ Fm ∧ ∃ K cHH eK CL x0,
    ∀ x ≥ x0, x ∈ Fm.Win → ChainTied Fm eD eL K cHH eK CL x

语义：**族 ℰ 在每个 eps 层级上有一个窗口族 Fm，其所有大窗口点全部被链绑定覆盖**。TopG（shapeWin 的输出）= 对每个满足宿主要求的特征类族 G.cls la，上述连通成立——"每个特征类在每个尺度都有绑定的窗口族"。

## 3. HypV：窗口族的 Sha 假设（同文件）

## 4. vvRecord：VVle 的展开定理（同文件）

VVle D.E D.R.t B ⇒ ShaFinOdd D ∧ Summable (vvTerm D) ∧ Σ' l, vvTerm D l ≤ B

- **vvTerm D l = log l · Σ_{e<t} shaLen(l, e)**（正文确认）——Sha 的素数加权对数级数
- ShaFinOdd：Sha 有限且指标为奇（genus 理论：2-部分由 genus 群控制，奇部分才是真 Sha——TwoPrimeField/Jacobi 词汇的出处）
- 无穷和 Σ' 收敛且 ≤ B——**级数化的 Sha 界**
