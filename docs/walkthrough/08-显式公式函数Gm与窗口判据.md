## 1. Gm：显式公式的引擎版右端（ExplicitFormulaErrorOfHostConditions.lean:38）

def Gm (y) := Formalism.Gz y + Σ_{psi ∈ Λ.Nt} Λ.wt psi * Re(An.gChi psi.chi y)

三层结构：

- **Gz y**：主项/基项（G 谱系的基准量）
- **Λ.Nt**：特征层级上的特征集；**wt**：权重
- **Re(gChi(ψχ, y))**：每个特征的正项和实部（解读 07 的 Landau 技巧产物）

对照经典显式公式 psi(x) = x − Σ_ρ x^rho/rho：经典式右端的"零点波"Σ x^rho/rho 是不可直接计算的（零点未知）；引擎版用**正项和的实部**替代——这正是 Landau 路线的动机：把"未知零点的波"换成"可估计的正项"。

## 2. 窗口化零点判据（ExplicitFormulaErrorOfHostConditions.lean:41 与 Window.lean）

def 桥（:41）：对所有 y ≥ y0 有 Gm y ≤ y^θ ⇒ Λ.ZeroFreeAbove θ

Window.lean:31 的等价形式：**集合 {x : Gm x ≤ x^θ} 若能被 [Y, Y^la] 窗口覆盖（HasWindows la）⇒ ZeroFreeAbove θ**

⇒ 零点自由不要求"处处"控制 Gm，只要求"窗口覆盖集内"控制——这就是为什么整个引擎都在造窗口族（Scales/HostFam/Ties*）：**在窗口里压住 Gm，窗口外自动失效也无妨**（Landau 判据的单调性接管其余）。反证方向（Window.lean:26）：若 Re>θ 有零点，则存在 y ∈ [Y, Y^la] 使 y^θ < Gm y（Gm 被"顶破"）——覆盖判据与反证等价。
