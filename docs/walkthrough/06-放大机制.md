# 解读 06 — 放大机制：窗口 Chebyshev 不等式与链绑定

> 对应第六轮侦察。TopWin.lean（140 行）是"局部条带非零 ⇒ 全右半带非零"的放大器，本篇解剖其完整数学。

## 1. 覆盖尺度：3/2 的结构来历（PrimeDiscriminants/Scales.lean）

structure Scales (la) 含三个成员：J（实数，1 ≤ J）、Win（实数集合）、windows（对每个 y 存在 Y 使区间 [Y, Y^la] 整个落在 Win 里）。

**la = 覆盖指数**：窗口族 Win 用几何级数窗 [Y, Y^la] 铺满所有大数。la > 1 是覆盖可行的充要条件（窗长 Y^la − Y 趋于无穷）；la 越接近 1 窗越薄。**VWinAt 的 [Y, Y^2] 是 la = 2 的特例；宿主层 Scales 取 la = 3/2** —— 更细的覆盖，这就是常数 3/2 的结构角色。配套工具：unb（无界性）、exists_mem（存在宿主尺度 ≥ y）、above（截尾）。

## 2. 放大定理的组件语义（TopWin.lean）

- WinAll Fm：窗口最终覆盖（存在 x0，凡 x ≥ x0 都在 Win 内）
- ChebyshevInequalityOnFamilyWindows / OnWindows(Λ) / AtWindowScale(la, Λ)：**切比雪夫型不等式**在特征 Λ = Level.cyc ψ 的窗口族上成立（指数参数 eD eL）
- TiedAll / ExWin / ChainWin：链绑定 / 存在窗口 / 链窗口
- tiedWin_of_ex：ExWin + ChainWin 推出 tiedWin
- level_of_tiedWin / level_of_tiedAll：窗口切比雪夫 + 链绑定 推出 ZeroFreeLevel
- zeroFreeOn_of_tiedWin_cyc (hla : 1 < la)：**总装放大器**—— cyc 级窗口链 推出 ZeroFreeOn

## 3. ChainTied：读数到 L 函数链的绑定（TieGlobal.lean:97）

ChainTied 是一个大型存在量化结构，核心成员：

- 读数对 av bv : N -> Z（对应 HostGood 的窗口读数 a(t), b(t)）
- 数据结构 Dd : Data A (Word) Top m f 与 Top 等价 TT、Fin f 等价 PhiSet（组合编码：词/顶/相）
- **Ident**：psi(n) = primVal D psi n 且 **ell psi = logDerivativeAtOne chi** —— 加性特征上的泛函 ell 等于 **chi 的 L 函数在 1 处的对数导数**
- LFunctionChainParameters.LChain.SizeData2 / ErrWindows / BNBounds / GrowthInequality / CostWindows / RestSize —— L 函数链的尺寸、误差窗、BN 界、增长不等式、成本窗、剩余尺寸

=> **ChainTied 把宿主读数绑定为"L 函数链"的参数，并识别 ell 为对数导数**。

## 4. 放大机制总图（引擎最后一块主拼图）

- 输入：每个特征有宿主（HostExW，la = 3/2）+ TopG（族连通）
- 机理：宿主窗口读数 → (ChainTied/Ident) 对数导数控制 → (窗口族上切比雪夫不等式) 窗口链 → (zeroFreeOn_of_tiedWin_cyc, la > 1) **psi.ZeroFreeAbove(1/2)**
- ZeroFreeOn := 对每个 psi 有 psi.ZeroFreeAbove(1/2)（ExplicitFormulaErrorOfHostConditions.lean:14）—— 右半带零点自由

**解读升级**：放大机制不是"逐步推薄条带"，而是经典 de la Vallée Poussin 结构的直接复活——切比雪夫型上界（对数导数或等价量）+ 窗口覆盖 => 对数导数无极点 => 零点自由。引擎的新颖性在于：经典路线的切比雪夫上界来自素数计数（Euclid 式），本证明的"窗口切比雪夫不等式"来自宿主舞台（Poitou-Tate 的 Sha 窗口 + 标签字典 + 链接网络插值）。即：

**经典骨架（1896）× 新燃料（Poitou-Tate + 朗兰兹机器）= 17.4M 行证明**
