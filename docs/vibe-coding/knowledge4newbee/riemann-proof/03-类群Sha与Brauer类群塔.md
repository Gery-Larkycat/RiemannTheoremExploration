# 数学背景 03 — 类群、Sha 与 Brauer 类群塔方法

> 面向零基础读者。读完你将理解引擎为什么盯着"Tate-Shafarevich 长度"不放。

## 1. 数域的类群：测量"理想世界偏离唯一分解"的程度

在数域的整数环里，唯一分解可能失效。补救：把"理想"按等价类分类，等价类构成有限群——**类群 Cl(K)**，其阶 h(K) 叫类数。h=1 表示该域里唯一分解成立。

## 2. Tate-Shafarevich 群 Sha：局部分解但全局不分的障碍

对椭圆曲线（或更一般的代数对象），**Sha[Ⅲ] 测量"在每个局部（每个素数 p 和实数处）都有解，但全局无解"的程度**。它是算术几何的中央谜团（BSD 猜想的一部分）。本项目 shaLen 是某类 Sha 型不变量的"长度"离散化（ℕ → ℕ → ℚ 的行数据）。

## 3. zeta 函数把类群和 Sha"定价"

数域 K 的 Dedekind zeta 函数 ζ_K(s) 在 s=1 的残差（residue）有显式公式：

res = (2^r · (2π)^s · h(K) · R(K) · Sha-ish) / (√|disc| · w)

即 **类群和 Sha 被编入 ζ_K 在 1 处的行为**。反过来：想控制 L 函数在 1 附近 ⇒ 控制类群/Sha ⇒ 需要它们的增长上界。

## 4. Brauer 类群塔：用塔控制类群

**Brauer 定理（1947 类群塔 + Brauer-Siegel）**：把数域 K 沿类群不断做类域扩张，得到塔 K = K₀ ⊂ K₁ ⊂ K₂ ⊂ …。若塔有限（比如停在某层），塔内各层的类数与判别式满足 Brauer-Siegel 型关系，从而**反推底层 K 的类群/Sha 的上界**。

直观：塔是"谐振腔"，塔的几何（判别式增长）约束每层的"音量"（类数、Sha）。这就是用"更大更几何的对象"控制"更小更算术的对象"的经典范例。

## 5. 本证明的做法：显式塔 + 指数界

窗口不等式（解读 03）的数学剧本：

1. 用一对手工设计的素数 (q ≡ 3 mod 8, d ≡ 7 mod 16, q | d+1) 与特征 ψ 联合切出一个分圈子域 E（IsChiField 判据）
2. 对 E 的 Galois 上同调数据读出 Sha 型长度行表（LData/shaLen）
3. 证明：长度的"对数加权指数和"在窗口内 ≤ e^(x^eps/2)（VVle）——一个指数级小的界
4. 通过显式公式（ExplicitFormulaError 家族），Sha 界翻译为特征 L 函数在右半带的非零性

为什么素数对要那些余律：mod 8 / mod 16 的约束让相关的 Jacobi 符号 (a/q)、(a/d) 与二次特征精确匹配，塔的 Galois 群结构被完全控制——这是类域论（Kronecker-Weber + 互反律）的精确运用。

## 术语速查

| 术语 | 一句话 |
|---|---|
| 类群 Cl(K) | 理想等价类群；阶 = 类数 h |
| 类域塔 | 逐层用类群做类域扩张的塔 |
| Sha | 局部处处有解、全局无解的障碍群 |
| Brauer-Siegel | h·R/√disc 在塔中的定量关系 |
| 判别式 disc | 数域的"体积"不变量 |
| residue（残差）| zeta 在 s=1 处留数，含 h·R·Sha |
| Jacobi 符号 (a/n) | 二次互反律的推广特征 |
| Kronecker-Weber | 所有阿贝尔扩张都在分圆域里 |
