# 数学背景 06 — 切比雪夫函数、显式公式与零点自由区

> 面向零基础读者。读完你将理解经典证明的引擎室：为什么"控制一个计数函数"就能逼出"零点不在某处"。

## 1. 切比雪夫函数 psi(x)

psi(x) := 对所有不超过 x 的素数幂 p^k 求和 log p —— 素数计数的"对数加权版"，比素数个数 pi(x) 更好用：乘法结构天然对数化。

**素数定理**：psi(x) 与 x 渐近相等。切比雪夫 1850 年证明了 psi(x) 的上下界夹逼（O(x)），虽未到渐近，但已够推出 Bertrand 公设（任意 x 与 2x 之间有素数）。

## 2. 显式公式：psi(x) 与 zeta 零点的对账单

**Riemann 显式公式**（1859）把 psi(x) 精确写成：

psi(x) = x − (对每个零点 rho 求和) x^rho / rho − 小项

直观：**素数分布 = 主项 x − 每个零点贡献的一份"波"**。零点实部 beta 越大，波幅 x^beta 越大、越乱。零点全在临界线上 ⟺ 波的振幅恰好是 x^(1/2) 级 ⟺ 素数分布的误差达到理论最小（同时控制了所有算术函数的误差）。

## 3. 反过来用：控制 psi 就能约束零点

看 log zeta(s) = 对素数 p 求和 对 k 求和 p^(-ks)/k（Euler 乘积取对数），这个正项级数在 Re(s) > 1 成立。经典论证三步：

1. 在 Re(s) 接近 1 处估计 log zeta 的增长率（用切比雪夫型上界控制 psi）
2. 得到 log zeta 的极点只能来自 s = 1（zeta 自己的极点）
3. => Re(s) > 阈值处 log zeta 无极点 => zeta 无零点

de la Vallée Poussin 1896 年由此得零点自由区：实部 ≥ 1 − c/log(虚部) 的竖条带（足够证明素数定理）。

## 4. L'/L(1,chi)：单个特征的"仪表读数"

对 Dirichlet 特征，对数导数 L'/L(1,chi) 是特征算术的集中体现：约等于对素数求和 chi(p) log p / p 的解析和。控制它 <=> 控制 chi 的素数加权分布 <=> 控制零点位置。

本证明的 Ident：ell psi = logDerivativeAtOne chi —— 引擎把宿主读数泛函 ell **识别为**对数导数，然后用窗口族上的"切比雪夫不等式"压住它。这正是经典路线的引擎室，只是上界的来源换成了 Poitou-Tate 机器。

## 5. 窗口覆盖：为什么需要 [Y, Y^la]

想对一切大 x 证明某不等式，手头只有几何级数隔开的窗口可用时，用 [Y, Y^la]（每步左端取 la 次幂）铺设半直线：

Y0, Y0^la, Y0^(la^2), ...

la > 1 保证窗口长度增长，最终覆盖一切大数；la 越接近 1，每窗越薄、估计在窗内越准。**3/2 是覆盖效率与估计精度的折中**——这就是 Scales la 的数学内容。
