# 数学背景 31 — Newton 多边形与斜率：p-adic 表示的指纹

> 面向零基础读者。读完你将理解"斜率"在 p-adic 数论中的含义——它与晶体上同调（crystallineComparison 常数的语境）相连。

## 1. 斜率从哪来

p-adic Galois 表示（或 Frobenius 幂级数）的"斜率"来自 **Newton 多边形**：把特征多项式的根按 p-adic 赋值大小排序，画出的分段折线。每段斜率 = 一组根的 p-adic 赋值平均值。

- 斜率是整数/分数 ⇒ 表示有特殊结构（晶体/半稳定）
- **晶体表示**：来自代数几何的表示（如椭圆曲线的 H¹），其 Newton 斜率 = Hodge 斜率（**比较定理**——解读 15/28 的 crystallineComparison 常数正是"两套斜率一致"的定理化）

## 2. 引擎语境

- 宿主 Q(√−q) 是 CM 域，其 Galois 表示的 Newton 斜率完全显式（CM 表示的斜率只有 0 和 1）
- 斜率族（SlopeLemmaFamily/SlopeLossFamily）= 表示在各素数位斜率的界的引理族
- **斜率界 ⇒ Frobenius 多项式系数的界 ⇒ L 函数系数的界 ⇒ 特征和的截断**——斜率是"几何侧供给解析侧"的又一转换器

## 3. 深嵌套的代数含义（组织学延伸）

源码中 23 层投影链对应嵌套结构体的层级——AI 把"假设包"层层打包（每层一个语义单位）。人类的数学论文用"编号引用"打平这种层级；Lean 里由投影访问。两种方式等价但可维护性不同——这是"AI 证明是否可维护"讨论的一个具体样本。
