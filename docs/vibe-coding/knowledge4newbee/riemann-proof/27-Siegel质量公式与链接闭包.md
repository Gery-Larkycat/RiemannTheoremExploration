# 数学背景 27 — Siegel 质量公式与链接闭包

> 面向零基础读者。读完你将理解"质量公式"为什么是类群的平均值计算器，以及"链接闭包"在图论意义上的角色。

## 1. Siegel 质量公式：类群的平均值机器

虚二次域 K 的"质量"定义为各类理想上权重的和（权重 = 1/自同构群大小）。**Siegel 质量公式**：

mass(K) = (√|disc| / 2π) · 修正乘积

它给出类群的总"体积"。**判别式十二次根**（解读 22）的来历之一：mass 公式中 √|disc| 除以修正因子，规范化后出现判别式的 1/12 型幂（历史上 Hilbert 的 mass formula 在局部域方向推广为普遍理论）。

引擎用途：mass 比率（SiegelMassRatio）= 两个域的 mass 之比——类群大小的**先验估计**。有了 mass 先验，类群的窗口读数（VWin）才有界可配。

## 2. 链接闭包：把"邻居"变成"同伙"

把素数看作图的顶点，Link 关系是边。**自反传递闭包**（ReflTransGen）= 从 p 出发沿边可达的所有顶点。flipTwoThree 断言：好顶点 p 的整个可达域里，翻转条件保持。

图论直觉：**如果翻转性质在每条边上都保持，它就在每个连通分量上保持**——把局部检查升级为分量级结论。这是"链接网络"设计（解读 11）的图论本质：用连通性代替逐点验证。

## 3. 编号族的组织学价值

AI 用 admF5/admF7/admF9 编号族管理"消失分支的容许性"：每个分支一个容许参数包。**编号系统 = 可寻址的引理网络**：

- 生成时按编号追加，无命名冲突
- 引用时精确到具体前提组合
- 缺点：人类读者失去语义助记——需要目录级地图（本项目 PROOF-MAP 的存在理由）
