# 数学背景 38 — 迷向空间与消失：对称双线性型的零化魔法

> 面向零基础读者。读完你将理解「迷向」这个词的几何含义，以及为什么迷向组上「一切相位消失」。

## 1. 对称双线性型：带内积的向量空间

给向量空间 V 配一个对称双线性型 hP（满足对称与双线性）。向量 v 的**范数** = hP(v, v)；两个向量**正交** = hP(v, w) = 0。

## 2. 迷向向量：自己与自己垂直

**迷向向量**（isotropic）：hP(v, v) = 0 的非零向量——**自己与自己垂直**的向量。在通常欧氏几何（正定型）中迷向向量只有零；但在不定型（signature 混合）或 p-adic 世界中，迷向向量大量存在。

**迷向子空间**：整个子空间 W ⊂ V 两两迷向（hP 限制在 W 上恒为零）。

## 3. 迷向 ⇒ 消失：相位级数的零化

引擎的相位级数 PhOn b = Σ_k phAt(lin 组合 b_k) 依赖 hP 的值。当 b 是迷向组（hP 全零）时，PhOn 的展开式中所有「交叉项」由 be（双线性偏差）承担——而 be 在迷向组上为零（PhIsotropic 前提）⇒ **整个 PhOn ≃ 0**。

直觉：迷向 = 「相位完全抵消的对称配置」——级数的每一项都被别的项精确抵消。

## 4. 消失如何变成界

HeightAndVanishing（高度与消失）的策略：

1. **高度条件**（判别式/结构约束）⇒ 宿主上的向量组是迷向的
2. 迷向 ⇒ 相位级数消失（PhIsotropic）
3. 消失的级数不需要估计——它就是零
4. 非迷向的部分（本原组）走另一个极端：正交分离（PhUnitary，可加分离）或对偶分解（PhDual）

**「消失区」+「分离区」两覆盖，全空间处理完毕**——这就是界证明的空间分解法。

## 5. √p 界：临界素数的收缩

jetPh 2（相位射流的 2 分量）在 p = d（宿主素数）处范数 ≤ √p：临界素数处的射流收缩为平方根。这与 RH 的 1/2 指数同构——**临界处的平方根收缩是整个理论的统一节拍**。
