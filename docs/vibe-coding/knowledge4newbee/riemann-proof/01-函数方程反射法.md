# 数学背景 01 — 函数方程反射法：为什么"右边非零"就够证明全部

> 本系列笔记独立于本项目成立，面向数学背景为零的读者。本项目源码对照用反引号标注。

## 1. Dirichlet 特征与 L 函数

**黎曼 ζ 函数**：ζ(s) = Σ 1/n^s。它编码素数分布。

**Dirichlet 特征** χ（模 N）：从"模 N 的乘法世界"到复数的函数，把整数按 mod N 分类后赋予 ±复数值，满足乘性。直观：一台"按 mod N 分类"的滤波器。

**L 函数**：L(s, χ) = Σ χ(n)/n^s —— 用特征加权的 ζ。ζ 自己就是模 1 主特征（全 1 滤波器）的 L 函数。

**GRH（广义黎曼猜想）**：所有 L(s,χ) 的非平凡零点都在 Re(s) = 1/2 直线上。ζ 版本就是 RH。本项目 Statements.lean 的四条 Prop 正是这个。

## 2. 完成函数与 Γ 因子

素数定理需要 ζ 沿竖直线的行为，裸 ζ(s) 在竖直方向衰减太慢。**完成函数**（completed L）在 L 前面乘上 Γ 因子（来自欧拉 Γ 函数）：

completed L(s,χ) = Γ 因子(χ,s) × L(s,χ)

Γ 因子把竖直方向"压平"到恰当的尺寸。本项目源码：gammaFactor χ s。

**关键事实**（本项目 Formalism.VW.gammaFactor_ne_zero）：Γ 因子在 Re(s) > 0 处从不为零。⇒ 完成函数的零点 = L 的零点（在右半平面）。

## 3. 函数方程：镜子的存在

完成 L 函数满足惊人的对称（函数方程）：completed L(s, χ) 与 completed L(1−s, χ⁻¹) 互为镜像。

即：χ 的 L 在 s 处的值，通过镜子看是 χ⁻¹ 的 L 在 1−s 处。直线 Re(s) = 1/2 恰是镜面。

## 4. 反射法：为什么只需证明右半边

想证：临界带 0 < Re(s) < 1 内的零点全在镜面上。分两种情况：

- **Re(s) > 1/2**：这是"右边"。若能证明右边全无非平凡零点 ⇒ 此情形自动安全。
- **Re(s) < 1/2**：设 s 处 L(s,χ) = 0。Γ 因子非零 ⇒ 完成函数在 s 为零 ⇒ 镜像：完成 L(1−s, χ⁻¹) = 0，且 1−s 的实部 > 1/2（进了右边）⇒ 与"右边非零"矛盾。

⇒ **只需证明：Re(s) > 1/2 处 L ≠ 0**，左半边由镜子免费送。

1896 年 Hadamard 与 de la Vallée Poussin 用这个结构（配上"右边 L 不为零"的弱化版本——零点不出现，只需增长性控制）证明了素数定理。本项目 Formalism.VW.critLine 是同一结构的完整版：右边全非零 ⇒ 零点全在镜面 = GRH。

## 5. "右边非零"从哪来——证明的真正引擎

上界估计：若能控制 |L(s,χ)| 的**上界**不趋于 0（比如 |L| 有正下界，或 |1/L| 上界有限），则 L ≠ 0。

经典 de la Vallée Poussin：构造 1/L 的近似（对数导数组合），用素数分布的增长估计控制它 ⇒ 右边无零点。

**Alpöge–Claude 证明的新颖处正在于此引擎**：UpperTheory.EveryCharacter（每个特征的右侧非零）由 GlobalTheory.GLq.Green（GL_q 的 Green 函数——谱几何/热核理论的输入）+ 窗口不等式（VWin）+ 形状命题（shapeWin）+ 特征供给（supplyChi）组装。朗兰兹式机器替代了经典素数计数估计——具体如何工作，见后续笔记。
