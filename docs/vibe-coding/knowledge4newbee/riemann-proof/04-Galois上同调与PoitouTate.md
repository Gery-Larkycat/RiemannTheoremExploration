# 数学背景 04 — Galois 上同调、Poitou-Tate 与 Selmer 群

> 面向零基础读者。读完你将明白"Sha 长度"为什么可以被公式定价。

## 1. Galois 上同调 H⁰ / H¹ / H²：三个问题三个答案

设 G = Galois 群（数域对称性的群），M 是 G 作用的模（比如 Q_l/Z_l 带分圆扭转）：

- **H⁰(G,M)** = 不动点 {m ∈ M : g·m = m ∀g} —— "G 完全无视 M 的哪些元素"
- **H¹(G,M)** = 交叉同态的等价类 —— "G 的扭曲/扩张方式"（主均匀空间：M 上 G-挠的 torsor）
- **H²(G,M)** = Brauer 类 —— "更深的扩张障碍"

直观：H⁰ 是"对称的平凡解"，H¹ 是"对称的扭转解"，H² 是"解不存在的障碍"。

## 2. Tate 扭转：用分圆特征给模"换挡"

分圆特征 χ_cyc：G → Z_l^× 描述 G 如何旋转 l-power 根（ζ_{l^n}）。定义 Z_l(n) = Z_l 配上 g·x := χ_cyc(g)^n · x —— 同一个群、换一个作用（第 n 档）。Q_l/Z_l(1−e) 同理。**不同的扭转档位对应完全不同的算术**：H⁰(Z_l(1)) 与单位根有关、H¹ 与类群有关、H² 与 Brauer 群有关。

## 3. 全局-局部原理与 Poitou-Tate

对数域 F 的每个位 v（素数 p 和实位）局部化 G → G_v，上同调也随之局部化：

全局 H¹(G,M) → Π_v H¹(G_v,M)

**Sha¹(M) := 这个映射的核** —— "在每个局部都可解、但全局不存在的类"。Poitou-Tate 定理给出全局与局部 H⁰,H¹,H² 之间的九项正合列，其中关键一段：

H²(G,M) → Π_v H²(G_v,M) → H⁰(G,M*)^∨ → H¹(G,M) → Π_v H¹(G_v,M) → H⁰(G,M*^*)^∨

本项目 VFormula 是其**长度化版本**（Z_l-模长度的守恒式）：VLen + 全局H⁰长 = shaLen + Σ局部H⁰长。把"正合性"翻译成"长度记账"——这是可估计化的关键一步。

## 4. Selmer 群：带边界条件的 H¹

Selmer(rho, {局部条件 L_v}) := H¹(G,M) 中满足每个位处局部约束 L_v 的元素。直观：**允许的扭曲解**——每个局部各开各的条件（有的位只许非分歧、有的位全放行）。Sha = Selmer 中"全局无法实现"的部分。selLen 就是 Selmer 的模长度。

## 5. Herbrand-Ribet 与本证明的关系

经典：分圆域 Q(ζ_l) 的类群 l-rank 由 Bernoulli 数控制（Herbrand 定理 1932，Ribet 证明 converse 1976）。其证明核心正是分圆扭转的 H¹/H² 长度比较（Herbrand 商）——与 VFormula 同骨。

本证明把这套机器用在**每个素数 l、每个窗口域**上，并用解析估计（Theta/Eisenstein）给出 Selmer/Sha 长度的**指数级小上界**（e^(x^eps/2)），再经显式公式推出 L 函数非零。可以把整座引擎概括为：

**"Poitou-Tate 长度记账 × 解析谱估计 ⇒ GRH"**

## 术语速查

| 术语 | 一句话 |
|---|---|
| 分圆特征 | G 打 l-power 单位根的旋转角 |
| Tate 扭转 Z_l(n) | 同一模、第 n 档分圆作用 |
| H¹ 交叉同态 | 扭转解的分类空间 |
| Sha¹ | 局部处处可解但全局不存在的类 |
| Poitou-Tate 列 | 全局-局部上同调的九项正合关系 |
| Selmer 群 | 满足逐位局部条件的 H¹ 子群 |
| Herbrand 商 | H⁰ 与 H² 长度比，控制类群 l-rank |
