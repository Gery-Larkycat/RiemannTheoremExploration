# 数学背景 20 — 特征的导子与水平：从 conductor 到宿主

> 面向零基础读者。读完你将理解"特征住在哪个模上"的层级结构，以及它为什么是引擎装配的关键接口。

## 1. 导子 conductor：特征的最小地址

Dirichlet 特征 χ 最初定义在模 N 上，但可能有"更小的真身"：存在最小模 N₀（conductor，导子），使 χ 在 N₀ 上已是特征。N 是 N₀ 的倍数时 χ 称为"以 N 为水平的非本原特征"。

- 本原特征：N = N₀（最小地址）
- 非本原特征：N > N₀（同一特征的"放大投影"）

**conductor 整除 N** 是结构律（本项目 level_dvd 引理：特征 χ 的 N 整除宿主 H.condN）。

## 2. 宿主水平：特征的家谱过滤器

引擎的宿主 H 有 condN（宿主水平，由素数对 q、d 及 2 幂次等合成）。生活在本宿主上的特征（H.IsCharE）都满足 N ∣ H.condN——**宿主水平像"门牌号集合"：只有地址匹配的特征才能入住**。

为什么这样设计：特征的 L 函数在 β ≈ 1 处的行为由其导子（真身地址）决定。宿主控制了 condN 的素数组成（q、d、2 幂、pde、pde'、q0 五素数仪表盘），于是：

- χ 的导子若含 q ⇒ χ 与虚二次域 Q(√−q) 的类域塔对话（解读 17）
- 若含 d ⇒ 对话 Q(√−d) 侧
- 若都不含 ⇒ χ 的导子"干净"（只有小素数和 q0）⇒ 走 SmallZeros 均匀带

**三条路线覆盖一切入住特征**（thinH 的分支结构），每条有独立的零点控制。

## 3. 水平的算术意义：L 函数的"因式分解"

非本原特征的 L 函数可分解：

L(s, χ以水平N) = L(s, χ₀本原) × Π_{p ∣ N/N₀} (1 − χ₀(p)/p^s)

（χ₀(p) = 0 当 p 整除导子）。即：**非本原 L = 本原 L × 有限个欧拉因子**。欧拉因子在 Re(s) > 0 处远离零（1 − 小量/s^σ），所以非本原 L 的零点行为由本原部分继承——这解释了为什么引擎只需控制本原情形（KatoLitO 的 Primitive、CritLine 的 IsPrimitive），非本原由 imprimitive 补齐引理（UpperTheory.Top.imprimitive）自动传导。

## 4. 历史注记

导子概念源自 Dirichlet 特征的最初研究（1870s-1880s）；本原/非本原的分解是解析数论的标准基础设施（判别式、双曲性、L 函数因式分解都靠它）。现代朗兰兹里，导子对应自守表示的"conductor of representation"——与解读 16 的 Hida 族、解读 02 的 Theta 对应同属一个大结构。
