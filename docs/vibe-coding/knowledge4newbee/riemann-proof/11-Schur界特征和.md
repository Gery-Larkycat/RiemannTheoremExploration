# 数学背景 11 — Schur 界：特征和的第一道栅栏

> 面向零基础读者。读完你将理解"特征和界"的传统范式，以及为什么引擎需要更深的机器。

## 1. 特征和：数论的心电图

对 Dirichlet 特征 chi，部分和 S(x) = 对 n 不超过 x 求和 chi(n)。它测量 chi 的"净偏移"：

- 主特征（恒 1）：S(x) = x 的下取整，巨大
- 非主特征：正负相消，S(x) 远小于 x——**相消程度 = L 函数的品性**

特征和的界越强，L 函数的行为越好（零点越少/越靠左）。

## 2. Schur 界（1918）

对模 q 的非主特征：

|S(x)| 不超过 (1 至 2)·sqrt(q)·log q 量级

证明出人意料地初等（两个周期段的差 + 完全分解），是"特征在完整周期内自相消"的直接体现。

## 3. Pólya–Vinogradov 界与"界的天花板"

任意区间 [M+1, M+N] 上同样有 sqrt(q) log q 级的界（Pólya 与 Vinogradov，1918）。特征和理论的一大主题是突破这个 sqrt(q) 天花板：

- **Burgess 界（1963）**：短区间上 x^(某分数) 级——几十年来最广的非平凡界
- **GRH 之下**：特征和可达 O(sqrt(q) log log q)——平方根截断
- **假定更强结构**（本证明路线）：从自守/上同调侧获得窗口级控制

关键对照：**GRH 供给平方根级特征和；反之特征和的平方根截断（引擎的 Gm ≤ x^(1/2+eps)）反过来逼出零点位置**——特征和与零点又一对偶（解读 10 的精神在特征层面的重演）。

## 4. "全局 Schur 界"：传统界为何不够、如何现代化

Schur/Pólya–Vinogradov 的 sqrt(q) 天花板依赖"模 q"这个经典载体，对"每个特征一张窗口"的需求（本证明的 VWin 窗口族）粒度不足。引擎的 GlobalSchurBounds 目录用 GL(3) Theta 对应 + 接合点网络（Joints/Link）把特征和的全局界重做成"链接层级"——把单一 sqrt(q) 天花板替换为**多层级、可逐特征实例化的界结构**（LinkGLOBAL7Tied4 等命名的层级语义）。

一句话：**Schur 给了第一道栅栏；本证明把栅栏升级为可编程的围墙网络。**
