# 数学背景 23 — CM 型与 Weyl 维数公式

> 面向零基础读者。读完你将理解"复乘型"的直觉与"表示维数公式"的样貌——引擎对称性与尺寸的两大控制源。

## 1. CM 型：虚二次域的"方向感"

CM 域（复乘域）= 全复的数域带一个特殊结构：**两份复嵌入中指定一份为" holomorphic"（全纯）方向**。对虚二次域 Q(√−d)：它有两个到 C 的嵌入（√−d ↦ ±i·√d），选一个就是**CM 型**。

为什么重要：复乘（CM）指椭圆曲线/自守对象的"额外对称性"来自虚二次域的算术。CM 型决定：

- 哪些 L 函数值是特殊值（解读 16 的临界值）
- 类群结构如何进入周期公式（判别式根，解读 22）
- **InducedCMType**：小域的 CM 型沿类域塔/模空间"诱导"到大结构上——引擎用 Kstar 的 CM 型作为整个宿主体系的对称性种子

## 2. Weyl 维数公式：表示的大小计算器

紧李群（如 GL(n)、其仿射群 GAf）的不可约表示都有有限维数，**Weyl 维数公式**给出显式计算：维数 = 各正根高度的乘积比。直观：维数由"表示的最高权重"决定，权重越高表示越大。

引擎的 GL3Columns/列格（解读 11）是一族列表示；**AdmittedWeylDimension** 说：这些列表示的 Weyl 维数被"容许界"控制（LevelDataRankBound/BasisWeightColumnCondition 提供权重约束）。

**为什么维数重要**：链绑定的组合账本（解读 14 的 m/f/Top/Card 条件）里，表示维数 = "账本行数"——维数失控则均方估计失效。Weyl 公式的容许界 = 账本行数的保险丝。

## 3. GAf：adelic 仿射群

GAf = 仿射群 G ⋊ A（线性群与平移群的半直积）的 adelic 版（对所有素数位同时）。自守表示的无穷小分析常在 GAf 上做（Iwasawa 分解、Siegel 集——解读 02/15 出现过的词汇都在 GAf 的舞台上）。
