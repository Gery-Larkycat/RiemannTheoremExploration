# 数学背景 28 — 椭圆曲线形式群：p-adic 世界的微积分舞台

> 面向零基础读者。读完你将理解「形式群」的直觉——它把椭圆曲线的加法几何翻译成纯幂级数代数。

## 1. 椭圆曲线：一条带群结构的曲线

椭圆曲线 E：y^2 = x^3 + ax + b（加上无穷远点）。它不只是曲线——**点与点之间有加法**（割线法几何构造），构成一个交换群。数论的一切戏剧（BSD、模性、Fermat）都在这个群上上演。

## 2. 形式群：在「无穷远点附近」的放大镜

无穷远点附近，曲线坐标失效。**形式群**用幂级数重新描述这附近的加法：

- 坐标换成参数 t（z/t 型）
- 加法变成幂级数：t(a+b) = F(t(a), t(b))，F 是二维幂级数 F(X,Y) = X + Y − a·XY + …
- **形式对数 log F**：把群运算线性化的幂级数（log(F(X,Y)) = log X + log Y 型）

本项目：flog W wq = 形式对数；ph = −log(ePhi1)；be a b = ph(a+b) − ph a − ph b（双线性偏差——**形式群加法的合格检验器**）。

## 3. p-adic 形式群：换到 p-adic 世界

系数放在 C_p（解读 21）里，同样的幂级数故事在 p-adic 世界重演：

- Weierstrass 曲线的 p-adic 模型（WeierstrassCurve.VariableChange）
- 嵌入 lam: Q̄ → C_p 给「代数数的 p-adic 化身」
- **CM 情形（本引擎！）：宿主 Q(√−q) 是 CM 域，ePhi1（CM 椭圆函数）把格与曲线连起来**——复乘的曲线在 p-adic 世界有超常好的形式群行为

## 4. 为什么椭圆曲线形式群是 RH 证明的一部分

回看链条（解读 22）：Theta 导数模性供给窗口读数。Theta 级数的积分表示（解读 12 Mellin）经过 **CM 椭圆曲线的形式群**（ePhi1 的 log 结构）——形式群的 Ok 公理保证积分表示收敛正确，be 双线性保证矩条件的可计算性。**p-adic 形式群是「几何侧供给」与「解析侧需求」之间的转换器**。
