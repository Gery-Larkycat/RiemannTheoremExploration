# 数学背景 17 — 虚二次域、genus 理论与二次互反律的计算

> 面向零基础读者。读完你将理解"两个手工素数如何造出一座算术性质完全透明的虚二次域"。

## 1. 虚二次域：最小的算术游乐场

K = Q(√−d)（d > 0 无平方因子）：把 −d 的平方根加进有理数。这类域小而精：

- 2 维（作为 Q-向量空间）
- 有"共轭"运算（√−d ↦ −√−d）
- 当 d ≡ 3 (mod 4) 时判别式恰为 −d（最简形式）

Q(√−q)（q ≡ 3 mod 8 素数）是最典型的样本：判别式 −q，类群较小（大 q 时类数 ~ √q），且是 CM 域（复乘理论的舞台）。

## 2. genus 理论：类群的"2-部分"完全透明

虚二次域类群的偶数部分（2-部分）由 **genus 理论**精确决定：

Cl(K) 的 2-rank = (素判别式因子个数) − 1

即：**判别式 −d 有几个素因子，类群的 2-部分就有几个独立生成元**——完全显式，无需计算类群本身！

引擎的 WinPair 设计（q ≡ 3 mod 8、d ≡ 7 mod 16、q | d+1、d+1 无小奇素因子）让组合域的 genus 结构完全可控：d+1 的素因子集合被钉死 ⇒ 相关 genus 群被钉死 ⇒ 类群的 2-部分可精确写出。这就是"手工素数对"的全部意义：**用互反律买来透明性**。

## 3. 二次互反律： Jacobi 符号的显式计算

引擎的 hjacb 引理计算：对 d+1 的每个小素因子 p，Jacobi 符号 (−d/p) = 1。

计算链：p | d+1 ⇒ −d ≡ 1 (mod p) ⇒ (−d/p) = (1/p) = 1（1 的 Jacobi 符号恒为 1）。

更深的版本（若 p ∤ d+1）用二次互反律：(−d/p) = (p/d′)·(符号修正)——**素数对余律（q ≡ 3 mod 8 等）正是让互反律的符号修正项全部确定为 1 的设计**。genus 理论的算术内核就是二次互反律。

## 4. 为什么虚二次域是"舞台"：复乘的影子

虚二次域有丰富的自守结构（其 L 函数、类域塔、椭圆曲线的复乘理论）——**它们是"小而完整"的算术宇宙**。引擎给每个特征配一座 Q(√−q)-型舞台，就是让特征在这个"完全可控的小宇宙"里展开其 L 函数，读出需要的界。
