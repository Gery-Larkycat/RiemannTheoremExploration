# 数学背景 10 — Landau 主项判据：素数定理与零点自由的对偶

> 面向零基础读者。读完你将理解"数素数就能知道零点在哪"这一深刻对偶，以及它如何成为引擎的"条件主定理"。

## 1. 一条古老的守恒律

素数计数与 zeta 零点互为镜像：

- psi(x) 的增长精度 当且仅当 零点不越过对应竖线
- psi(x) 与 x 渐近相等（素数定理）当且仅当 zeta 在 Re(s) = 1 上无零点（Hadamard 与 de la Vallée Poussin，1896）
- psi(x) = x + O(x^(1/2+eps)) 当且仅当 RH（零点全在 Re = 1/2）

这不是巧合：显式公式把两者写成恒等式，一方被控制则另一方被约束。**"数素数"与"找零点"是同一枚硬币的两面。**

## 2. Landau 主项判据的精确形式

引擎的条件主定理：

Gz y = 对 n 不超过 y 求和 vonMangoldt(n)·(y/n − 1) 不超过 y^θ（最终恒成立）=> zeta(s) 在 Re(s) > theta 无零点

直觉：Gz 是 psi(y) 的平滑化（对数权），若它以 y^theta 级增长，则 zeta 的对数导数的奇点只能在 Re ≤ theta —— 零点全被压进左区。

- theta = 1：素数定理级别（zeta 在 Re=1 无零点）
- theta = 1/2 + eps（任意 eps）：**恰为 RH**

## 3. 为什么"指数压到 1/2"等价于 RH

显式公式 psi(x) = x − 对零点 rho 求和 x^rho/rho：

- 若有零点实部 beta > 1/2，波幅 x^beta 会以 x^(1/2+) 之上翻腾 => 包络无法达到 1/2 级
- 反之若包络 ≤ x^(1/2+eps) 恒成立 => 不存在 beta > 1/2+eps 的零点 => 结合函数方程对称性 => 零点全在临界线

**"Gz 幂界 => RH"就是这条对偶的严格化**。引擎的全部工作（宿主/Poitou-Tate/标签字典/切比雪夫窗口）归结为一件事项：**把 Gz/Gm 的增长指数压到 1/2**。

## 4. 两条通道的分工（引擎的组织学）

- zeta 通道：只需主特征量 Gz——理论上素数计数一己之力可担
- GRH 通道：每个非主特征的波都要压制——需要每个特征一座宿主舞台

实际证明走 GRH 通道（EveryCharacter），因为：非主特征的波相互独立，逐个压制反而结构清晰（每个特征一个 Level/宿主/窗口），且 GRH 的结论更强（顺带覆盖无数 L 函数的应用）。
