# 数学背景 40 — Theta 平移公式与加权 L² 积分

> 面向零基础读者。读完你将理解 Theta 级数的平移符号律，以及「加权 L² 积分的幂公式」这一引擎的矩条件来源。

## 1. Theta 级数的平移符号律

经典 Theta 级数 theta(t) = Σ_n exp(−π·(t+n)²/area) 在格平移下满足：

theta 平移 x 的版本与原版之间相差一个**符号因子**，符号由「x 的范数平方（相对格面积）取整的奇偶性」决定。

引擎的 al1(x) = (−1)^round(√d/2 · |x|²/area(Λ)) 正是这个符号因子的显式形式——**√d 因子来自虚二次域的嵌入缩放**（解读 17/28）。

**直觉**：格点平移会翻转 Gauss 和的符号——符号翻转的「记账本」就是 al1。

## 2. 加权 L² 积分：normSq1

normSq1(Λ, G) = 在格的基本域上积分 |G(z)|² · exp(−π|z|²/area)

- **exp(−π|z|²/area) 是 Theta 核**——正好是 Theta 级数逐项的绝对值平方结构
- 加权保证积分收敛（Theta 级数本身可能增长）

normSq1 是「Theta 函数的**总能量**」——G 越大能量越大。

## 3. 幂公式：矩条件的指数来源

引擎 thPow：**normSq = normSq1^(fF·N·N')**。

N·N' 是格维数乘积（宿主表示的行×列）——**张量积结构**：N 行 × N' 列的读数 = N·N' 份独立信息，每份贡献一个 normSq1 的幂。fF 是引擎常数（格面积相关）。

**矩条件（th22 = C 阶矩等）的指数由维数乘积决定**——这就是「窗口读数指数」的来源。

## 4. 组装视角：45 条量规包

引擎把所有「局部良好性质」（模型存在/积分性/立方检验/双线性/CM 规范/共轭/分裂消失/对角/平移/2-挠/射流/正交分离/迷向消失/对偶分解/正交存在/Witt/isoF/…）打包为 **45 条合取的对数量规 aux₃**。容许条件 Adm3s（j-不变量整数性 + CM 型 + 宿主条件）⇒ aux₃。

**「3 条容许 ⇒ 45 条量规」**——这是引擎的「复利式」结构：少量深条件展开为大量浅性质。
