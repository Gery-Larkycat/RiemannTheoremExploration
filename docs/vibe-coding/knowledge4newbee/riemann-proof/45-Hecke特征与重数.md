# 数学背景 45 — Hecke 特征与重数：谱理论的计数器

> 面向零基础读者。读完你将理解「Hecke 算子」「特征向量」「重数」这三个自守谱理论的核心词，以及它们如何成为引擎的计数器。

## 1. Hecke 算子：模形式世界的对称算子

Hecke 算子 T_f 是作用在自守形式空间上的**交换算子族**（对应素数的算术操作）。本征尖形式（解读 16）正是所有 Hecke 算子的共同特征向量：T_f(f) = a_f · f（特征值 a_f 就是 q-展开系数）。

## 2. heckeEig：测试点的特征子空间

给定「测试点」x（宿主域上的算术点），heckeEig(T, act, x) = **所有 Hecke 算子 f 满足 f(x) = 特征值 · x 的公共特征子空间**（对每个 f 取特征空间再求交）。

即：**能同时被全部 Hecke 算子以特征值 f(x) 作用的最大子空间**。

## 3. heckeMult：重数判分歧

重数 = 特征子空间的分式域维数。

- mult = 1：特征向量唯一——「谱干净」
- mult > 1：特征退化——「多个形式共享同一特征值」（老形式/新形式理论的核心现象）

引擎用 mult 判断「特征是否退化」——退化的特征需要单独处理。

## 4. Wild 与 Tame 惯性

局部 Galois 群的惯性子群（固定剩余域的元素）有正规子群**野惯性群**（wild inertia，p-群）。商群 = **驯化惯性**（tame inertia，可循环）。

**TameGenAt**：γ 生成驯化惯性群——驯化部分的对称性由单个元素 γ 控制（驯化惯性是 pro-cyclic）。野部分（p-群）更狂野，需要单独的条件（宿主判别式不含 p 等）。

## 5. 分裂位判据的对称版本

IsSplitPl：存在 x ∈ v.asIdeal 且其**共轭** ∉ v.asIdeal——在 CM 域（自共轭）中，理想 v 的共轭 v' 不同 = v 分裂。**共轭对 (v, v')** 是 CM 域的标志性结构（解读 39 的 ± 嵌入对应）。
