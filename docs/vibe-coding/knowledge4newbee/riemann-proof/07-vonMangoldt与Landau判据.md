# 数学背景 07 — von Mangoldt 函数与 Landau 判据

> 面向零基础读者。读完你将理解"正项和的截断如何变成零点的缺席"。

## 1. von Mangoldt 函数 Λ(n)

Λ(n) := 若 n = p^k（素数幂）则 log p，否则 0。

它是切比雪夫 psi(x) = Σ_{n≤x} Λ(n) 的"逐点积木"。**一个数论量的平方根截断 = Σ Λ(n)·(特征)·(权) 的和被压到 x^(1/2+ε)**——这是"素数分布如随机"的精确化。

## 2. Landau 技巧：把 L'/L 变成正项和

对 L 函数取对数导数（s > 1）：

L'/L(s,χ) = −Σ Λ(n) χ(n) / n^s

**右边是带符号的级数**（χ 有正负）。Landau 的洞察（1918）：乘上 y^s 做积分，权重变成 log(y/n) ≥ 0：

对积分换序后得到 y·log y·(主项) − Σ_{n≤y} Λ(n)χ(n)·log(y/n)

若去掉特征（χ=1）全部为正 ⇒ 主特征情形实部可控。对一般 χ，实部 = 正项和（本项目 re_gChi：gChi 的实部 = Gchi 正项和）——**带符号问题被实部化约为正项问题**。

## 3. Landau 零点判据：指数型正实部函数无零点

设 P(s) 满足 P'(s) = q(s)·P(s)，其中 q 的实部恒 ≥ 0（q 正），且 P 在区域某点 ≠ 0，则 P 在区域处处 ≠ 0。

证明一行：F(s) = P(s)·exp(−∫q) 满足 F' = 0 ⇒ F 恒等于那一点的非零值 ⇒ P = F·exp(∫q) 处处非零（指数因子恒正）。

**这就是"正项和控制 ⇒ 零点缺席"的代数核心**：把 L 函数类对象写成指数型 P = exp(∫q)，正项和给出 q 的正性，判据给出零点缺席。本项目 logDerivZeroFree 就是它。

## 4. 平方根世界：截断与随机性

x^(1/2+ε) 为什么是"随机级别"：

- Σ_{n≤x} Λ(n)χ(n) 若 χ(n) 如掷硬币（±1 独立），部分和约为 √x（标准差 √(x·log x) 级）
- GRH 恰好等价于这类特征和的误差不超过 x^(1/2+ε)

所以"切比雪夫不等式的结论 Gm ≤ x^(1/2+(…7)·eps)"读作：**该特征和已达到随机平方根水平（带一个可趋于零的余项 eps）**——余项正是窗口化估计的机器常数集合（eD+eL+7）。

## 5. 两素数域与 Jacobi：Level 的构造词汇

- 特征的层级由素数对 (q,d) 生成（q≡3 mod 8，d≡7 mod 16，q|d+1）
- (a/q)、(a/d) Jacobi 符号决定"Galois 元 a 属于哪一层"
- 两素数的选择让层的 Galois 结构完全显式（二群扩展/Genus 理论）——这是类域论在二次域上的精确形式（genus 理论：GenSplit 文件名）

一句话：**用两个手工素数造一座 Galois 结构完全透明的塔，让每层特征都"有名有姓"**。
