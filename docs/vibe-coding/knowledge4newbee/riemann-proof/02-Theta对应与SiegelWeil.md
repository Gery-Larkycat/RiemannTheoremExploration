# 数学背景 02 — Theta 对应与 Siegel-Weil：引擎的解析机器

> 面向零基础读者。读完你将明白"Theta 级数为什么能给出特征和的界"。

## 1. 从特征和说起

证明引擎要控制所有 Dirichlet 特征的 L 函数。L 函数的解析行为由"特征和" S(χ) = Σ χ(n) e(n/N) 这类对象决定（e(x) = e^{2πix}）。经典手段（Pólya–Vinogradov、Burgess）给特征和上界，但都不够强到逼出 GRH。

## 2. Theta 级数：一台可调的谐波发生器

取一个"检验函数" φ（Schwartz 函数：光滑且急降），构造 Theta 级数：

Θ(φ, g) = Σ φ(n·g) （对格点求和）

它是模形式的近亲：对某个变换群有函数方程（这是 Poisson 求和公式的化身）。改变 φ 就改变这台发生器的"频谱"。

## 3. Weil 表示与 Howe 对偶

Theta 级数的变换规律由 Weil 表示（一个辛群的双值表示）掌控。两个互为"对偶"的经典群（比如某对称对 (G, G')）同时作用在 φ 所在的空间上——这造成一个奇迹：

一边的表示（自守表示 π）与另一边的表示（π'）互相决定对方。

这就是 Howe 对偶 / Theta 对应。它像一座桥：把难算的 G 一侧对象，搬运到更好算的 G' 一侧（往往是"更小"或"更几何"的群）。

## 4. Siegel-Weil 公式：Theta 级数 = Eisenstein 级数

Weil 的表示论 + Siegel 的计算给出惊人恒等式（在正则化意义下，部分情形成立）：

Theta 级数的积分 = Eisenstein 级数

左边是"谐波发生器"（分析），右边是"显式构造的模形式"（素数/格点的显式数据）。恒等式把分析对象翻译成可显式估计的量。

## 5. 为什么这套机器能顶替素数计数

经典 de la Vallée Poussin：素数分布的增长性 ⇒ 1/L 的控制 ⇒ 右半带非零。
Theta/Siegel-Weil 路线：显式 Eisenstein 侧 + 谱分解（Green 函数、尖形式衰减）⇒ 对每个特征的一致窗口估计 ⇒ 右半带非零。

一句话：把"素数有多少"的问题换成"谐波发生器的谱有多干净"。后者是几何/表示论问题，结构更强——这正是本证明把 70% 体积花在朗兰兹机器上的原因。

## 6. Green 函数速写

微分算子（拉普拉斯型）的逆核：给定算子 L，Green 函数 G(x,y) 满足 L G(·,y) = δ_y。谱上：G = Σ ψᵢ(x)ψᵢ(y)/λᵢ（特征函数与特征值）。它是"谱信息的总和"。GLq.Green 应即 GL_q 相关对象上的谱 Green 函数——引擎用它读取自守谱的形状。
