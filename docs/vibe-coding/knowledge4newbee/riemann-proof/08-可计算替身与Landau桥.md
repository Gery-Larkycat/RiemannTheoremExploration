# 数学背景 08 — 可计算替身：用正项和替代零点波

> 面向零基础读者。读完你将理解引擎最核心的"偷天换日"：把看不见的零点，换成算得动的正项。

## 1. 经典显式公式的尴尬

显式公式 psi(x) = x − Σ_零点ρ x^rho/rho 精确而美丽，但右端要**知道每一个零点**才能计算——而我们正在证明零点在哪里，鸡生蛋问题。

## 2. Landau 的替换术

考虑（s > 1 的实轴上）：

−L'/L(s, χ) = Σ Λ(n) χ(n) / n^s

乘上 y^s 并积分，权重变成 log(y/n)：

y^s 相关的积分 = y log y ·(主项) − Σ_{n≤y} Λ(n) χ(n) log(y/n)

三个关键性质：

1. **权重 log(y/n) ≥ 0**（n ≤ y 时）——正权
2. **右端是有限和**——只涉及 n ≤ y，全部可计算
3. **实部可分离**：Re(复量) = 正项和 Gchi（本项目 re_gChi 引理）

于是"未知零点的波"被替换为"已知素数的正项和"。引擎的 Gm 定义正是这个结构：

Gm y = Gz y（主项）+ Σ 权重 · Re(特征正项和)

## 3. 零点判据：正项和的截断推零点位置

Landau 型论证（本项目 logDerivZeroFree）：

- 把研究对象 P(s) 写成指数型：P(s) = P(s0) · exp(∫_{s0}^s q)
- q 的实部 = 正项和（可控！）
- 正项和 ≤ y^θ 型上界 ⇒ Re(∫q) 有界 ⇒ 指数因子不消失 ⇒ P 无零点

**直觉**：指数函数 exp(正实部积分) 永不为零——就像 e^x 没有实零点。正项和的界越强（θ 越小），零点被排除的区域越大（Re > θ）。θ 压到 1/2 = GRH 右半带。

## 4. 为什么只需要窗口覆盖

判断据（本项目 Window.lean:31）：集合 {x : Gm x ≤ x^θ} 被 [Y, Y^la] 窗口覆盖 ⇒ ZeroFreeAbove θ。

为什么"窗口内小，窗口外不管"就够：**单调性**。Gm 的定义使其在"对数尺度"上单调（主项与正项和都不剧烈回落），所以只要每个窗口的右端点处达标，整个窗口内部自动达标——窗口覆盖把"处处验证"降为"每窗验证一次"。这也是 la = 3/2 折中的意义：窗口越薄，"窗内插值"越安全。

## 5. 与经典理论的对照表

| 经典（1896-1918） | 本证明引擎版 |
