# 数学背景 09 — 主项与波：素数分布的乐理

> 面向零基础读者。读完你将理解"主项 + 波"这一贯穿解析数论的乐理结构，以及引擎如何分离它们。

## 1. 素数分布 = 主旋律 + 泛音

经典显式公式（解读 06）把素数计数写成：

psi(x) = x − Σ_零点 x^rho/rho + …

用乐理比喻：**x 是主旋律**（素数平均而言像 x 个音），**每个零点是一个泛音**（振幅 x^re(ρ) 的波）。素数定理只要求"泛音比主旋律轻"；RH 要求"所有泛音的音量恰为 x^(1/2)"。

## 2. 主特征与非主特征：一个交响乐团

ζ 函数对应主特征 χ=1（全 1 滤波器）；每个 Dirichlet 特征 χ 各有一个 L(s,χ)，各唱各的声部。对非主特征：

L'/L 的正项和（Landau 技巧后）= Σ Λ(n)·χ(n)·log(y/n)

由于 χ(n) 有正有负，这是"波"；但其**实部结构**（re_gChi）保证它可以被实值估计控制。

主特征的特殊性：χ=1 时正项和不抵消，得到**纯主项** Σ Λ(n)·log(y/n) ≈ y·log y − ψ(y)——这就是引擎的 Gz = Σ Λ(n)(y/n − 1)（log 的线性下近似）。

⇒ **Gm = 主项（主特征闭式）+ 波（非主特征实部和）**。ζ 与 L 的分离在引擎里就是 Gz 与 gChi 之和的分离。

## 3. 为什么主项有闭式而波没有

主项 Σ_{n≤y} Λ(n)(y/n−1) 只涉及"素数幂计数"这一原始对象（Λ 与 ζ 的关系），它的增长由素数定理级别的初等估计控制（恒有 O(y·log²y) 级粗界，且在 Landau 框架下它的作用是"恒正的基准"）。

波 Σ Λ(n)χ(n)(y/n−1) 含特征的相位信息，无法闭式估计——必须用更深的结构（周期/自守/上同调）。**引擎把全部困难集中在波上**：宿主舞台 + Poitou-Tate + 标签字典都只为压住波。

## 4. 窗口化单调判据的乐理重述

判据：波+主项的包络 Gm 在每个 [Y, Y^la] 窗口内不超过 y^(1/2+ε) ⇒ 高于 1/2 的泛音不存在。

乐理直觉：如果存在音量超过 x^(1/2+ε) 的泛音（零点 ρ，re ρ > 1/2+ε'），它在各自的"音区"（窗口）里会把包络顶破——窗口覆盖保证每个音区都被检查过。这就是反证方向（Window.lean:26）的直观。

## 5. Sha 的级数化：上同调的"频谱"

解读 04 的 Sha 与本篇 vvRecord 连接：Sha 的素数加权对数级数 Σ_l log l·Σ_e shaLen(l,e) ≤ B——**上同调群的"频谱"**（每个素数 l 一个频段，每段强度 shaLen）。Sha 级数收敛且小 = 频谱干净 = 舞台合格。类群/Sha 的 genus 理论（2-部分）对应"奇指标"（ShaFinOdd）——偶部分是结构性的（可精确控制），奇部分才是需要估计的自由度。
