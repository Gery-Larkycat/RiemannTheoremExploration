# 数学背景 30 — 形式群的立方结构与 Kudla 矩条件

> 面向零基础读者。读完你将理解"立方泛函"这个奇怪的词，以及它为什么是 Theta 导数理论的代数骨架。

## 1. 从双线性到立方：泛函的对称性阶梯

一个函数 f 的对称性阶梯：

- **线性**：f(a+b) = f(a) + f(b)（加法同态）
- **双线性**：B(a+b, c) = B(a,c) + B(a',c) 等（两变量各自线性）
- **立方（cubic）**：f 的三阶组合差为零——f(a+b+c) − f(a+b) − f(b+c) − f(c+a) + f(a) + f(b) + f(c) = f(a+b+c) 的立方检验

**立方泛函** = 二次型的推广（就像二次型是双线性型的"对角化"）。形式群理论中，log 结构的偏差 ph 常常是立方型——它的三次差为零使"矩条件"可以显式展开。

## 2. 引擎的 At 八推论就是这个阶梯

- beBiadd：be 双线性 ✓（第二阶）
- cube2/cube3/cube：ph 立方可加性 ✓（第三阶）
- addInt/endInt/phNorm：运算保持在积分世界 + CM 作用规范化

⇒ **形式群的加法/数乘/CM 作用全部有"多项式品质保证"**——矩条件（th22/mom22 等）因此可以像多项式恒等式一样逐项验证。

## 3. Kudla 理论中的角色

Kudla 的 Theta 导数理论中，关键对象是 **Theta 导数的"度量化圆括号"**（特殊点的导数值对）——它们的相容性恰好表现为立方型恒等式（cube 群）与双线性（beBiadd）。引擎把这些写成 At 的推论库，使得"九条矩条件"的验证变成**查库**而非重新发明。

## 4. 斜率族：误差指数的来源

局部二次部分（LocalQuadraticParts）的斜率引理族（SlopeLemmaFamily → eD）与斜率损失族（SlopeLossFamily → eL）：p-adic 形式群在分歧/惰性位的"斜率"给出误差指数。**eD + eL + 7 的构成 = 误差 + 损失 + 打包**——常数之谜完全关闭。
