# 数学背景 39 — CM 椭圆曲线的挠点与相对范数

> 面向零基础读者。读完你将理解「挠点」是什么、为什么素数分「分裂/惰性/分歧」三类，以及 CM 理论的相对范数缩放公式。

## 1. 椭圆曲线的挠点：有限阶的点

椭圆曲线 E 的点构成群。**n-挠点** E[n] = 满足 n·P = O（n 次加法后回到无穷远点）的点集。

- 复数域上：E[n] ≅ (Z/n)²（n² − 1 个非零 n-挠点）
- **2-挠点** E[2]：三个点（y = 0 的根）

挠点是椭圆曲线算术的「离散骨架」——Galois 表示（解读 16 Deligne 表示）的作用就体现在挠点上（Gal(Q̄/Q) 置换 E[n] 的点）。

## 2. 素数的三分类：分裂/惰性/分歧

对椭圆曲线（或数域）K 和素数 p：

- **分裂**：p 在 K 中分解为不同素理想——Jacobi 符号 = +1
- **惰性**：p 保持为一个素理想——Jacobi 符号 = −1
- **分歧**：p 带重复因子——判别式整除 p（只有有限个）

本引擎：SplitK = jacobiSym(−d, p) = 1、InertK = −1、分歧 = 宿主判别式素数。

**三分类的行为差异**（解读 38/39）：

- 分裂位：be/ph 完全消失（splitZero）——好位无贡献
- 惰性位：模型 ModelOverW + 规范化——坏位有结构
- 分歧位（p = d）：√p 临界收缩——特殊处理

## 3. 相对范数缩放：CM 元素的两张面孔

CM 元素 α ∈ K（虚二次域）有两个复嵌入像：α.1（全纯侧）和 α.2（反全纯侧）。它们的乘积 **N(α) = α.1·α.2 = 相对范数**。

引擎公式（phNorm）：**相位在 α 作用下的缩放因子 = N(α) = α.1·α.2**。

即：CM 作用把相位「按相对范数」重新标定——这是复乘理论的标志性现象（CM 的所有算术都经相对范数进入解析世界）。

## 4. 挠点的杀伤测试

IsTwoTorsionPointUnkilled：2-挠点 t 未被「杀伤」当且仅当 (1 + i√d)/2 · t ∉ Λ——**CM 元素 (1+i√d)/2 不能把 t 平移回格**。

「杀伤」直觉：一个 2-挠点若能被 CM 元素平移「抹掉」（平进格 Λ），它就没有独立的信息。未杀伤的 2-挠点是「活的」——携带真信息（解读 38：其 U1 级数有真奇性）。

## 5. Taylor 级数的 p-adic 化身

代数函数 G（复函数）的 p-adic 化身：取 G 的各阶导数在 0 处的值（Taylor 系数），经嵌入 lam 映入 C_p——**复函数的信息完整搬到 p-adic 世界**（ser1）。再经形式对数 l 代换（atU）——把「变量 z」换成「形式对数参数」。

这是复分析与 p-adic 分析之间**翻译机器**的实现：G 的信息 → Taylor 系数 → lam 嵌入 → p-adic 级数 → 形式群运算。
