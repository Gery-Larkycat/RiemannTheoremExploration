# 数学背景 35 — j-不变量与 1728：CM 椭圆曲线的身份证

> 面向零基础读者。读完你将理解 j-不变量是什么、为什么 1728 这个数如此特别、以及"CM 曲线的 j 是代数整数"为什么是定理。

## 1. j-不变量：椭圆曲线的身份证号

椭圆曲线 y² = x³ + ax + b 的形状由两个数决定：g₂（Eisenstein 系数）和 g₃。**j-不变量**：

j = 1728 · g₂³ / (g₂³ − 27·g₃²)

j 完全分类了复椭圆曲线（同构 ⟺ 同 j）。**1728 = 12³/2 = 2⁶·3³**——这个数的分母性质使 j 在 g₂³ = 27g₃²（退化情形）处规范化。

## 2. CM 曲线的 j 是代数整数

**经典定理（CM 理论核心）**：若椭圆曲线有复乘（CM）——即其自同构 End(E) 是虚二次域的序——则 **j(E) 是代数整数**，且 j(E) 生成虚二次域的 Hilbert 类域！

实例：j = 0 的曲线（y² = x³ + b）有 CM by Q(√−3)；j = 1728 的曲线有 CM by Q(√−1)。**1728 本身就是 Q(√−1) 的 CM j 值**——数字与理论的巧合之妙。

本引擎 admJ：**1728·g₂³ 是代数整数**——CM Weierstrass 模型的规范化不变量的整数性（j 的代数整数性的组件）。

## 3. 为什么引擎需要它

CM j-不变量的代数整数性 ⇒ j 的共轭（各嵌入的像）都是代数整数 ⇒ **各嵌入的 p-adic 范数 ≤ 1**（代数整数在所有非 Archimedede 嵌入处积分）⇒ **p-adic 形式群（解读 28 的 G1）在 CM 曲线上自动良好**——这就是解读 28"CM 曲线在 p-adic 世界有超常好行为"的代数根源。

## 4. PhiHat 与 kap 倒数权：上循环的归一化妙用

解读 34 的 2-上循环 kap 在此处作为**权重分母**：

PhiHat(y) = p^(−nr) · Σ_a Phi(a) / kap(vec(a), lift(y))

**上循环的倒数恰好归一化 Weil 算子求和**——投影表示的"障碍"被用作"权重"，坏事变资源。Xi(Phi=1) = 恒等（好素数处）进一步保证平凡情形无干扰。
