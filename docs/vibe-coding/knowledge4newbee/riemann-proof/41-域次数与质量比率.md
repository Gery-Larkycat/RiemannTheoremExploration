# 数学背景 41 — 域次数与质量比率：维数的算术意义

> 面向零基础读者。读完你将理解「域次数」在算术公式中的角色——它是所有算术量的「维数放大器」。

## 1. 域次数 [F:Q]

数域 F 作为有理数域 Q 上的向量空间的维数。例：Q 本身次数 1；Q(√−q)（虚二次域）次数 2；一般次数可以任意大。

次数 = 「域的复杂度」：次数越高，域内的数越多、算术越丰富。

## 2. 次数作为「放大器」

几乎所有算术公式的量都带次数因子：

- 判别式量级 ~ 次数的幂（disc ≈ 指数公式含 n）
- 类群大小 ~ √disc / log 型（含次数因子）
- **矩条件指数 fF·N·N'**：域次数 × 格维数——**每个自由度都贡献一个幂因子**

引擎 thPow 的幂公式把「矩条件指数 = 域次数 × 格行 × 格列」显式化——**维数记账的完备性**。

## 3. Siegel 质量比率

mass(F₁)/mass(F₂)（两个域的质量之比）= 比较两个算术宇宙的「密度」。质量公式的维数因子由域次数统一——**fF 在质量比率中的出现是「不同次数域可比」的保证**。

## 4. phW/beW：Frobenius 纤维的相位居

形式群理论有「两套实现」：
- p-adic 形式群（G1，解读 28）——固定素数 p 的局部理论
- **Frobenius 纤维版**（phW/beW）——Frobenius 算子纤维上的全局版本

两者平行的原因：Frobenius（素数 p 的算术对称）与形式群（p 位附近的几何）是同一枚硬币的两面（Crystal 理论的视角，解读 15 crystallineComparison）。
